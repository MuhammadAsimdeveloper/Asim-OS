# Asim-OS — Industry Tool Arsenal

Asim-OS is the local/offline workstation layer.

## Local-first priorities
JSON formatter/validator, JSON→TypeScript, Regex, JWT inspection, Base64/Binary, image optimization, palette/gradient, QR, code reviewer/explainer, secret/dependency audit, local sandbox, filesystem tools, notification/reminder, command center and device automation.

## Rule
Sensitive local files should remain local by default. Cloud/network tools require explicit opt-in and Aira permission policy.
